# Keytos Shield™ Forever-Lock — Worst Cancel Screen Ever Gauntlet

A satirical 7-stage enterprise SaaS cancellation gauntlet built with **Next.js (App Router, TypeScript, Tailwind CSS)**, **`matter-js` rigid-body physics**, **`motion` spring animations**, **`canvas-confetti`**, and a **zero-dependency procedural Web Audio synthesizer**.

Built to compete across **Most Confusing**, **Most Hostile**, and **Most Creative** by disguising psychological warfare inside a polished Zero-Trust PKI / EZCA / YubiKey billing portal (**Keytos Shield™ Forever-Lock Enterprise Suite**).

---

## Quickstart

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

For a production build:

```bash
npm run lint
npm run build
npm run start
```
